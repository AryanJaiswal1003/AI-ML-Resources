# Data Science & Machine Learning Reading Library

A curated collection of books and online resources for learning and applying
Python, statistics, data science, machine learning, data visualization, R,
distributed systems, and related technologies.

The folder contains downloadable reference books for offline study as well as
links to additional books, courses, and documentation available online.

## What is included

- **Python and data analysis** — Python programming, pandas, and practical
  data analysis
- **Statistics** — statistical thinking, inference, and applied methods
- **Machine learning and deep learning** — theory, algorithms, and practical
  implementations
- **Data engineering** — Spark, Hadoop, and large-scale data processing
- **R programming** — statistical computing and data mining with R
- **Data visualization** — visualization principles and tools
- **Computer networking** — high-performance web and network systems
